# 黑白界面实施计划与验收清单

依据：`AI虚拟手机黑白界面虚拟账号与好友码实施说明书.docx`（648 段）与 4 张设计图。
原则：先在现有仓库确认同名能力，能复用就不新写；不删除、不替换现有的聊天、身份、角色卡、工具调用、数据管理能力。

## 现有能力复用表（已确认）

| 说明书里的界面 | 仓库中已有的实现 | 处理方式 |
|---|---|---|
| 设置 | `components/phone-settings-app.tsx` + `CardGrid` 的 list 变体 | 复用，已有黑白列表 |
| 外观 | `components/phone-theme-app.tsx` | 复用，保留分区 |
| 记忆库 | `components/memory/*`、`lib/memory-*` | 复用数据层，只改外观 |
| 聊天列表 | `components/chat/phone-chat-app.tsx` | 复用，只改外观 |
| 聊天 Dock | `.chat-tab-bar`（`styles/chat.css`） | 复用，已加回弹 |
| 用户身份 | `lib/settings-storage.ts` 的 user identity | 复用，账号作为新对象叠加 |
| 角色卡 | `lib/character-storage.ts` | 不动 |
| 二维码 | `qrcode` 依赖（已装） | 复用 |

## 阶段划分

### P0 设计系统（已完成）
- `styles/design-tokens.css`：`--ui-bg/ink/muted/group/line/green`、字号阶梯、圆角与间距
- 验收：任意页面不出现非 token 颜色（除用户自定义主题）

### P1 设置与外观两页对齐设计图
- 设置：大标题 36px、分组列表、条目 17/24 + 14/21、右侧箭头
- 外观：2×2 卡片（主题/壁纸/图标/桌面组件）+ DESIGN SYSTEM / SYSTEM SETTINGS / ADVANCED 三段
- 验收：
  - [ ] 设置首页与二级页字号、圆角、分隔线一致
  - [ ] 外观首页四宫格间距与设计图一致
  - [ ] 不出现彩色玻璃图标

### P2 记忆库
- 顶部大标题 + 分段控件（记忆 / 角色）+ 搜索框
- 记忆按日期分组，每条含标题、摘要、更多按钮
- 底部黑色「新建」按钮
- 验收：
  - [ ] 记忆条数与真实数据一致
  - [ ] 切换分段不丢滚动位置
  - [ ] 空状态有引导文案

### P3 聊天列表与底部 Dock
- 搜索框、会话行（头像 / 名称 / 时间 / 摘要 / 未读点）
- 底部四段 Dock + 黑色圆形新建
- 验收：
  - [ ] 未读数与真实未读一致
  - [ ] Dock 按压有拉伸、松手回弹
  - [ ] 聊天室内部观感不变（本次不动聊天室）

### P4 虚拟账号与应用假登录
- 数据：`handle`、模拟密码（本地哈希，不存明文）、登录状态、`friendId`（稳定）与 `friendCode`（可刷新）分离
- 界面：账号与登录、我的资料
- 约束：不连接真实第三方、不收集真实密码；二维码不含密码/密钥/聊天内容
- 验收：
  - [ ] 刷新好友码不破坏已建立的好友关系
  - [ ] 无网络也能完成本地假登录
  - [ ] 旧数据读取失败时降级为空态，不清空

### P5 好友码与二维码
- 用户与每个 AI 角色都能生成好友身份与好友码
- 二维码内容只含 `friendCode` 与版本号
- 扫码优先 `BarcodeDetector`，不支持时提示手动输入
- 验收：
  - [ ] 扫码添加后生成正常好友关系记录
  - [ ] 二维码不含任何敏感字段
  - [ ] AI 添加用户时同样落到好友关系表

