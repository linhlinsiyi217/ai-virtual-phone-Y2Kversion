# 工坊 Claude 风格改造总清单

> 目标仓库：`linhlinsiyi217/ai-virtual-phone-Y2Kversion`
>
> 本清单合并了：当前 Y2K 工坊实际代码盘点、小笼包原版最新工坊差异、用户给出的完整开发指令、现有 Y2K 功能保护要求。它不是照抄提示词，而是后续开发与验收的唯一执行基线。

## 0. 不可违反的施工规则

- [x] 只修改 Y2Kversion；不再修改 float123 或 float-0217。
- [x] 先读现有实现和差异，再改代码；不整文件覆盖，不用旧仓库回退新功能。
- [x] 保留 Y2K 现有工坊引擎、GitHub、预览、提交确认、回滚、设备/诊断、会话和上下文压缩能力。
- [x] 只展示真实状态；没有连接、没有权限、没有执行成功时，不伪装为已完成。
- [x] 写仓库、删除、覆盖、提交、发布等有副作用操作必须保留确认与取消入口。
- [x] 不注入“关闭过滤、无条件服从、忽略系统规则”类越权提示词；它会破坏工具边界并增加误操作。需要的能力改为明确授权、真实工具和逐项确认。
- [x] 不清空用户数据，不改写 Git 历史，不覆盖其他人未提交改动。
- [x] 每一批只做相关文件；完成类型检查、构建/专项检查和移动端视觉检查后才能标为完成。
