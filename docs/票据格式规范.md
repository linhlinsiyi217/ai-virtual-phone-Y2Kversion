# Y2K 小手机 · 票据格式规范（v1）

> 一张 PNG 就是一张票据：既是能看的图，也是能导入的数据。
> 用在资源集市、心声美化、世界书、预设、正则等所有可分享的东西上。

## 1. 一张票长什么样

尺寸 1200×620（导出 2x，即 2400×1240），白底，四周留 32 边距，中间一条竖虚线打孔。

```
┌──────────────┬──────────────────┬────────────────┐
│ 左：票根      │ 中：预览          │ 右：模块清单    │
│ 头像 + 昵称   │ 真渲染的效果      │ 包含哪些部分     │
│ 备注短句      │                  │ 使用说明        │
│ 条形码        │                  │ 作者水印        │
└──────────────┴──────────────────┴────────────────┘
```

- **左**：`author.avatar`、`author.name`、`author.note`（资源集市里填的短句）
- **中**：用真实渲染器出的效果图，不是占位
- **右**：`modules[]` 逐项列出，附带一句怎么用

## 2. 数据怎么塞进 PNG

三道，按顺序读，第一道成功就不往下走：

| 顺序 | 载体 | 说明 |
|---|---|---|
| 1 | PNG `tEXt` 块，key = `y2k-ticket` | 标准做法，不破坏画面；转存时可能被剥掉 |
| 2 | 像素 LSB（右下角 8×h 区域） | 抗转发、抗重新保存；容量足够存 32KB |
| 3 | 票据上的二维码（在左栏条形码上方） | 最后兜底，肉眼可见 |

导入时依次尝试；全失败则提示"这张票没有可读数据，可能被压缩过"。

## 3. 数据结构

```json
{
  "format": "y2k-ticket",
  "version": 1,
  "id": "tk_20261111_8f3a",
  "type": "innerVoice",
  "name": "雨夜心声",
  "author": {
    "name": "林思伊",
    "avatar": "data:image/png;base64,...",
    "note": "写点小事的人"
  },
  "createdAt": "2026-11-11T01:20:00+08:00",
  "modules": ["prompt", "fields", "html", "motion"],
  "payload": { },
  "checksum": "sha256:..."
}
```

- `type` 决定 `payload` 的形状与导入后落到哪里
- `checksum` 对 `payload` 的规范化 JSON 求 sha256，导入时校验，不匹配就拒绝并提示
- `author` 可缺省；缺省时票据左栏显示"匿名"

## 4. 类型与负载

| type | payload | 导入落点 |
|---|---|---|
| `innerVoice` | `{ prompt, scenePrompt, fields[], html, motion }` | 心声美化 |
| `worldbook` | `{ entries[] }` | 世界书 |
| `preset` | `{ name, content, params }` | 预设 |
| `regex` | `{ rules[] }` | 正则规则 |
| `character` | `{ card, avatar }` | 角色导入 |
| `theme` | `{ css, vars }` | 外观 |

新增类型只需要加一行映射，不动票据本身。

## 5. 兼容与校验

- 只读 `version <= 当前支持版本`，高版本提示"请先更新应用"
- `checksum` 不符：拒绝导入，避免半损坏数据
- 缺字段：按各类型的默认值补齐，不因为少一个字段整张票失败
- 同一 `id` 重复导入：提示"已存在"，可选覆盖或另存为副本

## 6. 动画

| 动作 | 效果 | 时长 |
|---|---|---|
| 导出 | 卡片中线撕开，票根滑出并轻微上浮，落定 | 380ms，`cubic-bezier(.2,1.35,.35,1)` |
| 导入 | 票根从下方推入，虚线合拢，整卡弹一下 | 420ms |
| 失败 | 票根抖动两下（±6px），红色描边闪一次 | 260ms |

减少动态效果时全部退化为淡入淡出。

## 7. 安全

- 导入的 HTML/CSS 必须过净化：只允许样式与结构，剥掉脚本、事件属性、外链
- 图片体积上限 40MB；解析前先读文件头确认是 PNG
- 二维码内容与 payload 相同，不做额外跳转

## 8. 文件名

```
y2k-{type}-{name}-{yyyymmdd}.png
```

例：`y2k-innerVoice-雨夜心声-20261111.png`
